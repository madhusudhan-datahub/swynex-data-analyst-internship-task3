# SWYNEX Data Analyst Internship – Task 3

## Interactive Dashboard – Online Retail Sales & Customer Analytics

### Project Overview
This project is part of the SWYNEX Technologies Data Analyst Internship – Task 3.

The objective was to build an interactive and professional Power BI dashboard using the cleaned Online Retail dataset from the previous tasks.

### Tools Used
- Power BI
- Power Query
- DAX
- Microsoft Excel
- GitHub

### Dashboard Features

The dashboard provides an interactive view of:

- Total Revenue
- Total Quantity
- Total Invoices
- Average Order Value
- Total Customers
- Monthly Revenue Trend
- Revenue by Country
- Top 10 Products by Revenue
- Top 10 Products by Quantity

### Interactive Filters

Users can filter the dashboard using:

- Country
- Invoice Date
- Customer ID

### Key Findings

- Total Revenue: £10.64M
- Total Quantity: 5.57M
- Total Invoices: 19,960
- Average Order Value: £533.17
- Total Customers: 4,338
- The United Kingdom contributes the majority of total revenue.
- Revenue shows strong growth toward the later months of 2011, with November recording the highest monthly revenue.
- Product-level analysis highlights the highest-performing products by both revenue and quantity.

### Dataset

The dashboard uses the cleaned Online Retail dataset prepared during Task 1 and analyzed during Task 2.

### Project Outcome

A professional interactive Power BI dashboard was created to communicate key sales, product, country and customer insights through KPIs, charts and interactive filters.
